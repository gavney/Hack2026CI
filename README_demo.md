# Демонстрационный скрипт Cash Flow Radar для жюри хакатона

Универсальный скрипт запуска сквозного пайплайна прогнозирования кассовых разрывов с честным бэктестом (walk-forward без утечек данных), сравнением с базлайном ядра (Corridor v0.1) и стресс-тестированием What-If.

### Команды запуска
```bash
# 1. Быстрый смоук-тест за 4 секунды (1 компания, 3 окна):
python ML/demo/run_demo.py --data data/statements/C001.csv --out out/ --smoke-test

# 2. Полный запуск по одной компании или папке с компаниями:
python ML/demo/run_demo.py --data data/statements --out out/ --horizon 30 --step 7 --min-train-days 90 --threshold 0.5
```

### Параметры CLI
- `--data` (обязательный): путь к CSV-файлу (с `company_id`) или папке с выписками компаний
- `--out`: директория для сохранения отчетов и графиков (по умолчанию: `out/`)
- `--horizon`: горизонт прогнозирования в днях (по умолчанию: `30`)
- `--step`: шаг скользящего окна валидации в днях (по умолчанию: `7`)
- `--min-train-days`: минимальная длина обучающей истории до первой отсечки (по умолчанию: `90`)
- `--threshold`: рабочий порог вероятности кассового разрыва `P_any` (по умолчанию: `0.5`)
- `--smoke-test`: экспресс-прогон на 1 компании и 3 окнах для быстрой проверки

### Ключевые артефакты в `out/`
- `summary.md` — 1-страничный отчет для скриншотов с агрегатными метриками и статусами
- `metrics_overall.csv` и `.md`, `metrics_by_company.csv` и `.md` — полные таблицы метрик
- `threshold_sensitivity.csv` и `.md` — анализ чувствительности по порогам (0.2, 0.3, 0.5)
- `confusion_matrix.png` — матрица ошибок классификации кассовых разрывов (1600x900)
- `whatif.png` — стресс-сценарий внепланового расхода 2 000 000 руб. через EventsOverlayApplier
- `charts/forecast_<company>.png` и `forecast_<company>.csv` — суточные прогнозы и графики ликвидности
- `run.log` — полный журнал выполнения шагов с контролем PII-безопасности
