# Кассовый радар | Банк «Центр-инвест»

Интеллектуальный сервис финансового прогнозирования и предотвращения кассовых разрывов для малого бизнеса (ИП и ООО). Разработано для кейса **Банка «Центр-инвест» (Хакатон Осень 2026)**.

---

## 🌟 Ключевые возможности

### 1. Траектория остатка и коридор P10–P90 (Версия 0.1)
- **Прогноз на 30–90 дней вперед** на базе интерфейса `Forecaster` (контракт раздела 10.2 ТЗ).
- Расчет коридора неопределенности: $P50 \pm 1.28 \times \sigma \times \sqrt{t}$.
- Расчет вероятности кассового разрыва `prob_negative` (с учетом овердрафта).
- Маркеры `model_version: "stub-0.1"` и `quality: "low"` для прозрачности.

### 2. Светофор и разбор («Почему / Сколько / Что делать»)
- **Жёсткий порог**: остаток $< 0$ (с учетом лимита овердрафта).
- **Мягкий порог**: остаток $<$ обязательных платежей на ближайшие 7 дней.
- **3 персональных действия** с оценкой финансового эффекта:
  1. Запрос досрочной оплаты у клиентов (+X ₽)
  2. Перенос срока оплаты поставщику (+Y ₽)
  3. Активация смарт-овердрафта банка «Центр-инвест» под 0% на 7 дней (+Z ₽)

### 3. Интеграции и коннекторы (1С, ФНС, Банк, ЭДО, Маркетплейсы)
- **1С:Предприятие 8.3**:
  - Синхронизация выставленных счетов покупателям и входящих счетов поставщиков через mock OData API.
  - Генерация и выгрузка выписки в официальном формате обмена **`1CClientBankExchange` v1.03** (Windows-1251).
- **ФНС России (ЕНС)**:
  - Синхронизация сальдо Единого налогового счета (ЕНС).
  - Автоматический учет уплаты ЕНП 28-го числа (со сдвигом на рабочий день по производственному календарю РФ).
  - Проверка рисков блокировки счетов по **ст. 76 НК РФ**.
  - Сервис проверки надежности контрагентов (**Федресурс**, банкротство, арбитраж).
- **Банк «Центр-инвест» (ДБО / АБС)**:
  - Графики аннуитетных платежей по кредитам и лизингу.
  - Зарплатный реестр.
- **ЭДО (Диадок / СБИС)** и **Маркетплейсы (WB / Ozon)**:
  - Учет условий постоплаты и графиков выплат.

### 4. Сценарии стресс-тестирования «Что если»
- Задержка оплаты от ключевого клиента (+14, +21, +28 дней).
- Падение выручки на 10%, 20%, 30%.
- Внеплановый крупный расход (ремонт, штраф).
- Рост постоянных расходов (аренда, закупки на 15%).
- График сравнения «База против Сценария» на одной шкале.

### 5. Дизайн в стиле Центр-Инвест, Sber & Apple Wallet
- Цветовая палитра банка «Центр-инвест» (фирменный изумруд `#00A859`, `#059669`, `#10B981`).
- Банковские карты Wallet с отображением расчетных счетов, овердрафта и быстрых действий.
- Виджеты выгодных предложений банка (депозит овернайт 14.2%, смарт-овердрафт, факторинг, СБП).
- Виджет курсов валют ЦБ РФ.
- Адаптивность для смартфонов ($\ge 360px$) и ноутбуков.

## 🗄 Модель данных (БД)

Архитектура базы данных реализована на **SQLAlchemy 2.0** с поддержкой **SQLite** (по умолчанию, с режимом `WAL` и поддержкой внешних ключей) и легким переключением на **PostgreSQL** через переменную окружения `DATABASE_URL`.

Таблицы:
- `companies`: профиль, ИНН (строка с сохранением ведущих нулей), форма, отрасль, овердрафт, налоговый режим.
- `operations`: история движения денег, нормализованные поля, статус дубликата, категории.
- `categories`: дерево категорий с ролями (`regular_out`, `tax`, `variable_in`, `variable_out`, `one_off`, `transfer_own`, `refund`).
- `category_memory`: память правок пользователя `(norm_purpose + inn) -> category`.
- `slots`: регулярные платежи (день месяца, типичная медианная сумма, повторяемость).
- `events`: ожидаемые будущие события (дата, сумма, вероятность, источник, статус план-факт).
- `forecasts` & `forecast_days`: сохраненные траектории прогноза и коридора.
- `alerts`: предупреждения о кассовых разрывах с рекомендациями.
- `scenarios`: параметры сценариев «что если».
- `integration_sources`: реестр подключенных внешних систем (1С, ФНС, ДБО).
- `audit_logs`: журнал аудита безопасности (без PII и сумм).

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
pip install fastapi uvicorn pydantic pydantic-settings sqlalchemy pandas numpy python-multipart pytest
```

### 2. Заполнение базы данных (Seeder)
```bash
python -m backend.seed
```

### 3. Запуск веб-сервера
```bash
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```

Приложение доступно по адресу:
- **Веб-интерфейс**: [http://127.0.0.1:8000](http://127.0.0.1:8000)
- **Интерактивная документация Swagger API**: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- **Проверка здоровья сервиса**: [http://127.0.0.1:8000/health](http://127.0.0.1:8000/health)

### 4. Запуск тестов
```bash
python -m pytest tests
```
Все 9 unit-тестов проверяют очистку данных, каскад категорий, нормализацию ЕНП, контракт `Forecaster` и сценарии.
